# kr_screener — 한국 주식 아침 스크리닝 (1단계)

> **이 단계의 목표는 "돈 버는 봇"이 아니라 "나만의 리서치·데이터 도구"다.**
> 자동매매 없음. 리스크 0. 전일(EOD) 데이터로 *어제 거래량을 동반해 급등한 종목*을
> 걸러 **오늘의 관심 워치리스트**를 만든다. 실시간 예측이 아니라 **모멘텀 연속성 후보 발굴**.

전체 로드맵: **1) 데이터·리서치 도구(지금)** → 2) 백테스트 검증 → 3) 모의투자 → 4) 소액 실전.
아직 1단계다. 여기서 시장 이해를 쌓고, 2단계에서 "이 스크리닝이 실제로 수익이 났나"를 냉정하게 검증한다.

---

## 무엇을 하나

매일 아침(장 시작 전) 실행하면:

1. **전 종목 스냅샷** 수집 (KOSPI+KOSDAQ, 전일 OHLCV·거래대금·시가총액)
2. **유니버스 필터** — 보통주만, 유동성/시가총액 밴드
3. **급등 필터** — 전일 등락률 또는 장중 고가율
4. **거래량 급증** 계산 — 전일 거래량 vs 직전 20일 평균
5. **스코어링** → 상위 N개 워치리스트
6. **SQLite 저장 + CSV + 콘솔 표** 출력

매일 스냅샷을 DB에 쌓으므로, 시간이 지나면 그 자체가 **백테스트(2단계)용 히스토리 자산**이 된다.

임계값은 **합리적 기본값일 뿐**이다. 어떤 값이 실제로 유효한지는 2단계 백테스트로 검증한다.

## 알려진 한계 (반드시 인지)

- **EOD(종가) 기반이다.** 실시간 호가/체결이 아니다. "오늘 장중 급등할 종목"을 예측하지
  못한다. 이 워치리스트는 *어제 급등한 종목을 오늘 지켜본다*는 관찰 도구다.
- **FDR 두 백엔드 불일치.** `StockListing`(스냅샷)과 `DataReader`(히스토리)가 같은 날
  종가/거래량을 미세하게 다르게 줄 때가 있다(소스가 다름). 정밀 검증이 필요하면
  실전 단계에서 키움/증권사 API로 교차확인한다.
- **장중 고가율 급등의 함정 → 종가강도로 해결(#2).** 장중 +30% 찍고 밀린 종목은
  `MIN_CLOSE_STRENGTH`(종가강도)와 `MIN_CLOSE_RET`(급락마감 배제)로 걸러진다.
- **자동매매 아님.** 주문/체결 기능 없음. 의도적으로 리스크 0으로 시작한다.

## 다음 단계

### A. 재무 수집 (DART) — ✅ 구현됨
- 워치리스트 각 종목에 **연간 사업보고서 주요계정**(매출/영업이익/당기순이익/자산·부채·자본)
  을 붙이고, 부채비율·영업이익률을 계산해 표/CSV/DB(`financials` 테이블)에 저장.
- `config.DART_APPLY_FILTER=True` 면 **"급등 + 재무 양호"** 2차 필터 적용:
  - `FIN_REQUIRE_OP_PROFIT_POSITIVE` — 영업이익 흑자
  - `FIN_MAX_DEBT_RATIO` — 부채비율 상한(기본 200%)
  - `FIN_MIN_OP_MARGIN` — 영업이익률 하한(옵션)
- 설정: `.env` 에 `DART_API_KEY=...`, `config.DART_ENABLED=True`.
  corp_code 매핑과 재무는 `data/` 에 캐시되어 재실행 시 빠름.
- 키 발급: https://opendart.fss.or.kr/ → **인증키 신청/관리** → 이메일 인증 → 즉시 무료.
- ⚠️ **보안**: 실제 키는 `.env`(gitignore됨)에만 두세요. 공유되는 템플릿 `.env.example`
  에는 키를 넣지 마세요.
- 한계: 신규 상장사는 연간 사업보고서가 없어 재무가 `nan` (필터 시 제외됨).
  연초에는 직전연도 보고서가 아직 미공시일 수 있어 재작년치로 자동 폴백.

### C. 백테스트 (2단계, 단기 스크리너) — ✅ 구현됨 (`bt_fetch.py` → `bt_run.py`)
- `bt_fetch.py`: 유니버스(현재 259종목)의 과거 2년 일봉을 `daily_prices` 에 적재.
- `bt_run.py`: 과거일별로 스크리닝을 재현(no look-ahead) → D+1 시가 매수 →
  익절/손절/시간 청산 → **수수료+거래세+슬리피지 차감** → 유니버스 평균과 edge 비교.

**결과 (259종목 · 약 2년 · 왕복비용 ≈ 0.51% · 익절7%/손절-4%/3일보유):**

| 구분 | n | 승률 | 평균/거래 | PF |
|------|---|------|-----------|----|
| 신호매매 **net(비용반영)** | 2369 | 31.7% | **-1.08%** | 0.63 |
| 신호매매 gross(비용제외) | 2369 | 31.9% | -0.57% | 0.78 |
| edge비교: 신호 종목(gross, 고정보유) | 2337 | 43.0% | +0.63% | 1.15 |
| edge비교: 유니버스 전체(기준선) | 115,875 | 45.9% | +0.28% | 1.12 |

**결론 (정직하게):**
1. **현 상태로 실매매 금지.** 익절7%/손절-4% 규칙은 net -1.08%/거래로 **손실**.
   청산 1527건이 손절(익절 663) — 변동성 큰 급등주에 -4% 손절은 노이즈에 먼저 걸린다.
2. **미약한 gross edge는 존재.** 신호 종목의 3일 고정보유 수익(+0.63%)이 유니버스
   평균(+0.28%)보다 **+0.35%p** 높다. 스크리닝이 아무거나 사는 것보단 낫다는 신호.
3. **그러나 edge(+0.35%p) < 왕복비용(0.51%).** 비용을 넘지 못해 실전 흑자로 이어지지
   않는다. 옆 폴더 `../backtest/`(업비트 스캘핑)와 **동일한 결론**: *현실적 비용 아래에서
   단기 edge는 대부분 소멸한다.*
4. 손절규칙이 오히려 수익을 깎는다(고정보유 gross +0.63% > TP/SL gross -0.57%).

### C-2. 파라미터 스윕 (`bt_tune.py`) — ⚠️ 반전과 함정
청산 조합 150개 스윕 결과, **손절을 제거하면** 여러 조합이 비용을 넘었다:
- `손절없음/익절없음/10일보유`: net **+2.64%**/거래 (PF 1.37), `…/5일`: +1.04%.
- 즉 "급등주는 손절로 자르면 되돌림 상승을 놓친다"가 in-sample 으로 확인됨.

**그러나 이건 거의 확실히 생존편향 착시다.** 손절 없는 장기보유 전략은 *상장폐지로
0이 된 종목이 데이터에서 빠진 것*에 가장 크게 부풀려진다(우리 유니버스=오늘 살아남은
259종목). 손절 버전이 더 나빠 보이는 건 오히려 그게 더 정직하기 때문. 게다가 최고
조합조차 **중앙값은 여전히 마이너스(-2.38%)** — 소수 대박이 평균을 끌어올린 팻테일이라
승률 44%로 심리적으로 가혹하다. **상폐 포함 시점정합 유니버스 없이는 신뢰 불가.**

### C-3. 재무 필터 검증 (`bt_fin.py`) — 재무는 오히려 역효과
- 급등+**재무양호** gross +0.09% < 급등+**재무부실** gross **+1.53%** (기준선 +0.28%).
- 단기 급등 모멘텀은 **잡주/테마주(재무 부실)에서 나온다.** 재무 양호 필터는 edge 있는
  종목을 걸러내 버린다 → **"급등 + 재무 양호" 조합은 무의미하거나 역효과.**
- 단, 재무부실 subset 의 높은 수익은 생존편향+'재무없음(신규상장/스팩)' 이 특히 부풀린
  값이라 **가장 신뢰도 낮다.** 잡주 모멘텀 추종은 최고위험 게임.

**한계(결과는 낙관 편향):** 유니버스=오늘 상장 종목(생존편향) · 상장폐지/거래정지
미반영 · look-ahead 재무 · 동일봉 익손절은 손절 우선 가정. 실제 edge는 이보다 낮을 것.
**핵심 교훈: 시점정합(point-in-time) + 상폐 포함 데이터 없이는 백테스트를 믿지 말 것.**
